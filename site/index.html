O CrowdSec no browser, sem abrir SSH.

A Sentinela mostra quem o CrowdSec bloqueou e porquê, o que o WAF travou, e deixa desbloquear um IP, instalar uma regra ou gerir uma allowlist com dois cliques. Corre no seu servidor e só fala com a API local.

curl -fsSL https://sentinela.nozaf.ao/instalar.sh | sudo bash

Prefere ler o script antes de o correr como root? Faça assim.

O que bloqueou, e porquê

Decisões activas, alertas com os eventos e o contexto, e o que o componente AppSec analisou e bloqueou, regra a regra.

As tarefas de todos os dias

Bloquear ou desbloquear um IP ou uma gama, instalar colecções e regras de virtual patching, gerir allowlists, recarregar o CrowdSec.

Fechada por omissão

Escuta só em 127.0.0.1 ou na VPN. Palavra-passe com bcrypt e TOTP, ou atrás do Authelia. Cada alteração fica registada.

Porque existe

Quase tudo no CrowdSec passa pelo cscli. Um cliente liga a dizer que o IP do escritório foi bloqueado: liga-se a VPN, entra-se por SSH, procura-se a decisão, apaga-se. Para saber se o WAF está a travar alguma coisa, mais um comando. A Sentinela junta esse trabalho numa página, no próprio servidor, sem serviço externo e sem base de dados própria.

É um único binário em Go, de código aberto (licença MIT), feito em Angola por Gelson Fernandes.

In English: Sentinela is a small, self-hosted web interface for CrowdSec. Read the README on GitHub.
